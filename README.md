## Что пошло не так (Troubleshooting)
В ходе выполнения лабораторной работы возникло несколько нюансов:
1.  **Ошибка `target is busy` при отмонтировании:** При попытке отмонтировать раздел `/mnt/data1` для смены опций монтирования (Задание 3) система выдавала ошибку, так как текущий рабочий каталог терминала находился внутри этого раздела. Проблема была решена переходом в корневой каталог (`cd /`) или использованием ленивого отмонтирования (`umount -l`).
2.  **Защита `mkfs`:** При попытке отформатировать раздел, который не был отмонтирован, `mkfs.ext4` выдал ошибку `is mounted; will not make a filesystem here!`. Это защитный механизм, предотвращающий случайное уничтожение данных на работающей файловой системе.
3.  **Лимит inode (Задание 4):** При запросе `mkfs.ext4 -N 64` (всего 64 inode) файловая система ext4 проигнорировала точное значение и создала технический минимум — 512 inode. В связи с этим цикл создания файлов пришлось запускать не до 100, а до 600, чтобы наглядно продемонстрировать переполнение таблицы inode.
4.  **Синтаксис циклов в bash:** При попытке запустить цикл `for` через `sudo for i in ...` возникала синтаксическая ошибка. Было выяснено, что `sudo` применяется к конкретным командам, а для выполнения циклов от имени суперпользователя необходимо сначала получить root-права через `sudo bash`, и уже затем выполнять конструкции оболочки.
